# T-0028: De Bruijn Universal Sequence Frontier & Lyndon Word Concatenation Exact Certification ($k \le 4, n \le 6$)

## Goal

Exhaustively generate and certify the exact de Bruijn sequences $B(k, n)$ using lexicographic Lyndon word concatenation (Fredricksen-Maiorana algorithm) and shift register state graphs across parameter tuples $(k, n) \in \{(2, 1..6), (3, 1..4), (4, 1..3)\}$. Verify perfect $n$-window coverage (100% of the $k^n$ distinct $n$-gram substrings occur exactly once as contiguous cyclic windows with zero duplicates and zero omissions). Verify theoretical sequence counting formulas $N(2, n) = 2^{2^{n-1}-n}$ (matching OEIS A000402) for $n \in \{1, 2, 3, 4, 5\}$, export all canonical sequences to a machine-readable JSON dataset, and audit all sequence certificates with an independent pure Python verifier.
