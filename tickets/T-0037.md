# T-0037: Waring's Problem Exact Small Power Minimum Sums Frontier ($k=2, 3, 4, 5, N \le 100000$)

## Goal

Compute the exact minimum power decomposition length $r_k(n)$ for all integers $n \le 100,000$ across powers $k \in \{2, 3, 4, 5\}$. Verify that $r_k(n) \le g(k)$ holds across 100% of tested integers with exactly 0 counterexamples. Catalog all extremal integers achieving $r_k(n) = g(k)$, export machine-readable decomposition certificates in JSON format, and audit with an independent pure Python verifier.
