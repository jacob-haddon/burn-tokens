# T-0025: Constructive Chinese Remainder Theorem & Modular Congruence Solvability in Lean 4

## Goal

Formalize from first principles in Lean 4 (without external Mathlib dependencies):
1. **Constructive CRT Solver**: A computable function `crt2 : Nat → Nat → Nat → Nat → Option Nat` that takes coprime moduli $m_1, m_2$ and residues $a_1, a_2$, returning the canonical simultaneous solution $x \in [0, m_1 m_2)$.
2. **Soundness Theorems**:
   - `crt_mod_left`: $x \equiv a_1 \pmod{m_1}$.
   - `crt_mod_right`: $x \equiv a_2 \pmod{m_2}$.
   - `crt_range`: $x < m_1 m_2$.
3. **Strict Uniqueness Theorem**: Any two solutions $x, y \in [0, m_1 m_2)$ satisfying the simultaneous congruences must be identical ($x = y$).
4. Clean compilation with `lake build` / `lake env lean`, zero `sorry` declarations, and standard core Lean 4 foundational axioms.
