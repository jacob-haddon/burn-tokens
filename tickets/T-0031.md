# T-0031: Ruzsa Triangle Inequality & Exact Additive Difference Distance Frontier ($|A|, |B|, |C| \le 6$)

## Goal

Exhaustively explore, stress-test, and certify the fundamental Ruzsa triangle inequality:
\[
|A| \cdot |B - C| \le |A - B| \cdot |A - C|
\]
and the induced Ruzsa metric distance $d(B, C) \le d(A, B) + d(A, C)$ across over $10^6$ subset triples $(A, B, C)$ with $|A|, |B|, |C| \le 6$ in $\mathbb{Z} \cap [-15, 15]$:
1. Build a high-performance Rust exploration engine `ruzsa_engine` in `projects/02-counterexample-observatory/ruzsa_engine/`.
2. Verify zero counterexamples to $|A| |B - C| \le |A - B| |A - C|$ and $d(B, C) \le d(A, B) + d(A, C)$.
3. Catalog extremal triples achieving sharp equality ($R(A, B, C) = 1$) and minimum/maximum Ruzsa distances.
4. Export complete machine-readable dataset to `projects/02-counterexample-observatory/data/ruzsa_distance_frontier.json`.
5. Build an independent pure Python verifier `ruzsa_verifier.py` validating all difference sets and metric properties from scratch.
6. Append telemetry to `runs.jsonl`, update `BOARD.md`, and write a result note and handoff.
