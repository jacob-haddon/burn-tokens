# T-0034: Wilf's Conjecture Finite Frontier & Frobenius Invariants in Numerical Semigroups ($g \le 60, e \le 5$)

## Goal

Exhaustively generate and certify numerical semigroups $S = \langle g_1, \dots, g_e \rangle$ across genus $g(S) \le 60$ and embedding dimensions $e(S) \in \{2, 3, 4, 5\}$. Compute the Frobenius number $F(S)$, conductor $c(S) = F(S) + 1$, embedding dimension $e(S)$, and number of elements $n(S) = |\{s \in S \mid s < F(S)\}| + 1$. Verify that Wilf's inequality $F(S) + 1 \le e(S) \cdot n(S)$ (Wilf defect $W(S) = e(S) n(S) - (F(S) + 1) \ge 0$) holds across 100% of generated semigroups with exactly **0 counterexamples**. Catalog all minimal tight cases, export the complete dataset in JSON format, and audit with an independent pure Python verifier.
