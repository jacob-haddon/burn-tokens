# T-0009: Graceful Tree Conjecture Finite Certificate Generator ($n \le 16$)

## Goal
Generate and verify graceful labelings for all non-isomorphic trees up to $n = 16$. Emit an exact certificate dictionary mapping canonical tree structures to bijective vertex labelings $f: V \to \{0, \dots, n-1\}$ such that edge differences $|f(u) - f(v)|$ cover all $\{1, \dots, n-1\}$.
