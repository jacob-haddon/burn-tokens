# T-0024: Free Monoid Construction, Categorical Universal Property, and Unit Isomorphism in Lean 4

## Goal

Produce a self-contained, machine-checked formalization in Lean 4 (without Mathlib dependencies) of:
1. The **Free Monoid** construction on any type $\alpha$ via `List \alpha` under list concatenation (`++`) and empty list (`[]`).
2. The canonical generator inclusion `of : \alpha \to \text{FreeMonoid}(\alpha)`.
3. The **Categorical Universal Lift**: for any monoid $M$ and map $f : \alpha \to M$, the fold map `lift f : \text{FreeMonoid}(\alpha) \to M` is a valid monoid homomorphism.
4. The triangle commutation identity: $\text{lift}(f) \circ \text{of} = f$.
5. The **Categorical Uniqueness**: any monoid homomorphism $h : \text{FreeMonoid}(\alpha) \to M$ satisfying $h \circ \text{of} = f$ is strictly identical to $\text{lift}(f)$ ($h = \text{lift } f$).
6. Functorial map lifting and the singleton canonical isomorphism $\text{FreeMonoid}(\text{Unit}) \cong (\mathbb{N}, +, 0)$.
7. Zero `sorry` declarations and standard foundational core axioms (`[propext, Quot.sound]`).
