# T-0023: Complete Lattice Galois Adjunctions & Knaster-Tarski Fixed-Point Formalization in Lean 4

## Goal

Formalize from first principles in Lean 4 (without external Mathlib dependencies):
1. **Complete Lattice Structure**: Posets equipped with arbitrary joins (`sSup`) and meets (`sInf`) satisfying universal bounding and bounding-bound properties.
2. **Galois Adjoint Preservation**:
   - Lower adjoint $f$ preserves all arbitrary joins: $f(\text{sSup } S) = \text{sSup } (f '' S)$.
   - Upper adjoint $g$ preserves all arbitrary meets: $g(\text{sInf } T) = \text{sInf } (g '' T)$.
3. **Knaster-Tarski Fixed-Point Theorem**:
   - Every monotone function $h : L \to L$ on a complete lattice has a least fixed point $\mu h = \text{sInf } \{ x \mid h(x) \le x \}$ and a greatest fixed point $\nu h = \text{sSup } \{ x \mid x \le h(x) \}$.
   - Proof that $h(\mu h) = \mu h$ and $h(\nu h) = \nu h$.
   - Proof of extremal minimality and maximality among all fixed points.
4. **Machine Check**: Zero `sorry` declarations and 0 custom axioms.
