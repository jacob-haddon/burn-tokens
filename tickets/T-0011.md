# T-0011: Davenport Constant and Minimal Zero-Sum Sequences in Small Non-Abelian Groups ($|G| \le 32$)

## Goal

Compute and verify exact values of the small and large Davenport constants $D(G)$ and $\mathsf{D}(G)$ for all non-abelian groups of order $|G| \le 32$ (including dihedral groups $D_{2n}$, dicyclic/quaternion groups $Dic_n$, alternating group $A_4$, and semidirect products). Catalog maximal zero-sum free sequences and certify zero-sum completeness with an independent Python verifier.

- Machine-readable JSON artifact with catalog of all computed group structures and maximal zero-sum free sequences.
- Result note adhering to `AGENTS.md` format.
